# Εγχειρίδιο Εσωτερικών Χρηστών Enomos

Η πλατφόρμα **Enomos** επιτρέπει στους φορείς να παρακολουθούν τις αιτήσεις διαμεσολάβησης που τους αφορούν, να ορίζουν τον νομικό συνεργάτη που θα αναλάβει κάθε υπόθεση και να επικοινωνούν με τον Ενόμο.

!!! note

    Το εγχειρίδιο αυτό απευθύνεται σε **εσωτερικούς χρήστες** της ΡΑΑΕΥ. Όπως και στους φορείς, ο λογαριασμός σας στο Enomos **δεν είναι κοινός** με την πλατφόρμα myraaey.gr.

## Περιεχόμενα

Στο εγχειρίδιο περιγράφονται τα παρακάτω:

- **[Πρόσβαση](access.md)**: σύνδεση στην πλατφόρμα και επαναφορά κωδικού.
- **[Αιτήσεις](applications.md)**: λίστα και καταστάσεις αιτήσεων, ορισμός νομικού συνεργάτη και συνομιλία με τον Ενόμο.
- **[Χρήστες](users.md)**: προσθήκη, επεξεργασία και απενεργοποίηση των χρηστών του φορέα (μόνο για διαχειριστές οργανισμού).
- **[Ρυθμίσεις](settings.md)**: μενού χρήστη, γλώσσα και ειδοποιήσεις.

## Ρόλοι

| Ρόλος | Τι κάνει |
|-------|----------|
| **Διαχειριστής οργανισμού** | Βλέπει τις αιτήσεις που έχει διαμοιραστεί ο Ενόμος με τον φορέα, ορίζει νομικό συνεργάτη και διαχειρίζεται τους χρήστες του φορέα. |
| **Χρήστης οργανισμού** | Βλέπει τις αιτήσεις στις οποίες έχει οριστεί νομικός συνεργάτης. |

## Γρήγορο ξεκίνημα

1. [Συνδεθείτε](access.md) στο Enomos πατώντας **Σύνδεση ως ΡΑΑΕΥ**.
2. Ανοίξτε τη [λίστα αιτήσεων](applications.md#list) για να δείτε τις αιτήσεις που σας αφορούν.
3. Αν είστε διαχειριστής οργανισμού, [ορίστε τον νομικό συνεργάτη](applications.md#assign-representative) κάθε αίτησης.
4. Παρακολουθήστε την πορεία της αίτησης από τη [σελίδα της αίτησης](applications.md#view) και επικοινωνήστε με τον Ενόμο μέσω της συνομιλίας.
